## Cấu trúc dự án
Hệ thống sử dụng kiến trúc Client-Server với sự phân tách rõ ràng giữa frontend và backend.
- **Frontend (React)**: Đóng vai trò là client, xử lý giao diện người dùng và gửi yêu cầu (requests) đến backend thông qua API.
- **Backend (Express, Node.js)**: Đóng vai trò là server, xử lý logic nghiệp vụ, quản lý dữ liệu, và trả về các phản hồi (responses) cho client.
